# 脫穎而出戰略（Differentiation Strategy）

> 前提：所有隊伍都會用 AI coding 高速產碼——「做得出能動的 dashboard + Bedrock 聊天」不再是門檻。本文件回答：同質化之下，分數從哪裡拉開、我們靠什麼被記住。
> 方法：3 個獨立研究視角（對手模擬／陽明海事專家品評模擬／評審心理與簡報戰術），合成為可執行 backlog。
> 鐵律：所有差異化項目**不得擠壓 55% 硬盤**（dashboard 30% + FUEL_CONSUMP 25%）的既定工時；全部基於現行定稿架構 v1.0（`12` §4），**零架構變更**。
> 狀態：Draft，待團隊 review 後才回寫 `09`／`10`。
>
> **命名 legend（防撞名）**：本文 D1–D9＝產品差異化項、P1–P11＝**呈現層差異化項**；P0/P1/P2 單獨出現時＝優先級；架構路線 P1/P2 見 `09` §2.2／`11`；**團隊第 5 位成員稱「P5 成員」**（見 `02`），與本文呈現項 P5 無關。

## 1. 核心論點：門檻消失後，鑑別點上移

當 5+ 隊都有能動的 dashboard 與 Bedrock 聊天時，五個評分維度的實際鑑別力重新洗牌：

| 維度 | 同質化後的真實鑑別點 |
| --- | --- |
| FUEL_CONSUMP 25%（程式打分） | **唯一零主觀硬分差**。預估半數隊在多燃料換算／全量 vs 篩選口徑／格式精度掉 30–50% 分 |
| Speed Loss dashboard 30%（專家品評） | 不是圖表美醜，是「數字像不像真的」：量級合理性（正常 2–10%，畫出 40% 的隊出局）、有沒有控制 slow steaming／載況／天氣、before-after 口徑、Q&A 講不講得出行話 |
| 商務 20% | 「錢化＋可執行」：講「提升效率」拿基本分，講「這艘船年多燒 47 萬美元、清潔 4 萬、回本 1 個月」拿滿分 |
| 技術 15% | 「裁決過的簡單」勝過服務數量——前提是你能證明簡單是決策不是能力上限 |
| AI 創意 10% | 不是聊天流暢度（人人都有），是 AI 的角色設計：citation 可回溯、防幻覺、human-in-the-loop |
| （隱形第六維）Q&A 4 分鐘 | 同質 demo 之下，被問倒＝前面 8 分鐘全部貶值；主動揭露限制的隊被專家記住 |

**一句話定位**：全場都會有 dashboard 和 AI 聊天；只有我們把「這艘船該不該清、現在清划不划算」算成錢，並讓 AI 說的每個數字可以點回證據。

**Slogan（首尾呼應，12 字）**：「數字來自計算，語言來自 AI，決策留給人。」

## 2. 對手地圖（8 原型 × 對策）

| 原型 | 出現機率 | 他們贏我們的點 | 我們的對策 |
| --- | --- | --- | --- |
| QuickSight BI 速成隊 | 3–4 隊 | 視覺第一印象 | Demo 開場 30 秒內秀出他們給不出的 Speed Loss %，口頭點名「這不是 raw 油耗」 |
| Bedrock RAG 聊天隊 | 2–3 隊 | AI 創意的「哇」效果 | citation 點回互動排進 demo；Q&A 主動講「LLM 不碰數字，因為 25% 自動評分容不下幻覺」——把對手炫點重定義成風險 |
| SageMaker 煉丹隊 | 1–2 隊 | 技術 15%（若模型真的準） | 防守稿：「ISO 19030 本身就是確定性方法；篩後樣本量 ML 必過擬合」＋秀 Theil-Sen／斷點偵測證明不是不會統計 |
| Bedrock Agents 炫技隊 | 1–2 隊 | 創意 10% 幾乎必贏我們 | **認賠**。demo 快取＋generated_at 是反制鏡像：他們現場賭延遲，我們證明真實但不賭 |
| **同型紮實工程隊** | 1–2 隊 | 全維度貼身肉搏 | 勝負在細節三件套：誠實限制聲明／before-after 同口徑／商務錢化（§3 D1–D2） |
| 過度工程微服務隊 | 1–2 隊 | 技術 15%（架構圖唬人） | 「被淘汰架構對照頁」：六路線研究證明簡單是裁決（§3 P4） |
| 商務敘事顧問隊 | 1–2 隊 | 商務 20% 拿 8–9 成 | 偷他們的招：單船案例經濟學頁，用真資料算的「有根的錢」 |
| 預測性維護排程隊 | 0–1 隊 | prescriptive 故事壓我們 | 不跟進做預測（3 天不誠實）；用 Theil-Sen 斜率 × 90 天的零成本外推欄位吃掉一半效果（§3 D6） |

**資源配置結論**：認賠創意 10%（不追炫技）與部分技術 15%（不追服務數量）；鎖死 55% 硬盤＋商務 20% 的單船經濟學，把 Q&A 當第六維度準備——這是前二名的牌型。

## 4. 專家品評防守清單（30% 的另一半）

研究確認的 8 個「翻白眼錯誤」我方已全部避開（速度正規化／假精確／吃水／過度歸因／ML 黑箱／基準窗／圖表罪行／越權建議）——這在全場已是前三名方法論。剩下的是**呈現紀律**：

1. 限制主動講，不等 Q&A 被挖（P5）。
2. Demo 全程正確術語：biofouling、AF coating、propeller polishing（與 hull cleaning 是兩件事、效果 2–4% 量級）、FOC 單位 MT/day。由最熟的人上台講這 3 分鐘。
3. 五大追問已備答（基準怎麼定／slow steaming 怎麼分離／3.2% 該不該花 4 萬清／SOG 黑潮怎麼辦／歸因 68% 憑什麼）——全部對應 `09` §4 既有設計＋本文件 P6 附錄頁。

## 5. 認賠清單（刻意不做）

| 不做 | 理由 |
| --- | --- |
| 追創意 10% 的 agent 炫技 | 輸 2–3 分換 55% 穩定領先，划算 |
| 追技術 15% 的服務數量 | 「裁決過的簡單」＋P4 減法頁是更高分的答法 |
| 預測模型（prescriptive 全套） | 3 天做不誠實；D6 外推欄位吃掉一半效果 |
| QuickSight 級視覺打磨 | 30% 評的是數字可信度不是美醜；template 及格即可 |
