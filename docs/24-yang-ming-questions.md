# 給陽明海運 / 主辦方的問題清單（Day1 現場 + 線上 Q&A）

> 依已讀的官方 workshop 頁、命題頁與**實際資料集**（`vt_fd.csv` 21,282 列 / `maintenance.csv` 77 筆 / README）整理。
> 問題按對象與優先度排。**🔴 = 直接決定 25% 客觀評分或會卡住開發，10:00 說明會必問**。

## A. 評分與提交機制（🔴 最高優先 — 對主辦方/陽明）

1. 🔴 **油耗預測的評分指標到底是什麼**？RMSE、MAPE、還是其他？對 102 格是等權平均，還是逐燃料/逐船加權？比對的是 MT/day 絕對值還是相對誤差？
2. 🔴 **預測 `submission.csv` 交到哪、格式為何**？併入本組 surveycake 表單當附件，還是另有上傳口？欄位確認是 `ship_id,day,fuel_type,predicted_value`、共 102 列？
3. 🔴 **提交值語義確認**：predicted_value = 當日**全速時段內**實際消耗的該燃料油量（MT，原始欄位語義），**不是**正規化到 24h 或固定時數？（README 這樣寫，但因牽動整條校正邏輯要當面確認。）
4. 評分是賽中即時 leaderboard，還是賽末一次性結算？可否賽中試交看分數？

## B. 資料語義（🔴 讀資料後發現的真實模糊點 — 對陽明資料方）

5. 🔴 **時間軸錨點**：`vt_fd.csv` 的 `NOON_UTC` 是各船相對天數（Day0=該船最早紀錄）；`maintenance.csv` 用日曆日期。**Day0 是全船隊同一個日曆日，還是逐船不同**？我們實測「全船隊同錨」只對上 14 個養護事件中的 7 個，需要正確的日曆對應才能精準把養護事件接到日報上。可否直接提供各船 Day0 的日曆日期（或確認 join key）？
6. **H 類欄位**（HORSE_POWER、LOAD_PCT、SFOC、THRUST…）在預測窗被 HIDDEN。訓練窗的 SFOC 若可用，幾乎能直接反推油耗——這是**刻意給的建模輔助**還是應避免的洩漏？期望我們用它到什麼程度？
7. **ME_AVG_RPM**（A 類、預測窗可見）在我們的模型是最強特徵（重要度 0.86）。確認 RPM 對預測日是真實觀測值、不是本身就洩漏答案的代理欄位？
8. **STW vs SOG** 兩欄皆 100% 填充但因洋流有差。陽明認為與油耗/ISO 19030 效能關係「物理正確」的是哪一個？貴司營運上有無既定的洋流/潮流修正法？
9. **TOTAL_CONSUMP / ME_FULLSPEED_CONSUMP_* / ME_CONSUMPTION** 三者關係：目標是 `ME_FULLSPEED_CONSUMP_<fuel>`，確認它就是「全速時段主機該燃料總量」、與 `HOURS_FULL_SPEED` 的對應關係？
10. 燃料熱值表 BIO_HSFO 標 39.4*（近似）。預測窗我們驗證只有 HSHFO(91)/VLSFO(11) 無 BIO——確認無誤；跨燃料熱值折算是「模型內要做」還是「僅供比較」？

## C. Speed Loss / ISO 19030（30% dashboard — 對陽明專家）

11. 期望對齊到 **ISO 19030 的哪個層級**？完整 ISO 19030-2（含各項修正）還是 noon-report 粒度的務實改編？貴司認可的**參考基準期**是什麼（進塢後海試曲線 vs 首 N 個合格日）？
12. **船殼 vs 螺旋槳歸因**：貴司有無偏好的物理拆分法或預期量級？貴司自己的 UWC/PP 紀錄有無可當 ground-truth 的效能恢復幅度？
13. 養護事件效應確認：UWI=純檢查無改善（已明示）；DD 含全面塗裝→恢復近乎完全；UWC 為部分——這樣的分級對嗎？還有其他細節（如 PP 只影響螺旋槳分量）？
14. 貴司實務上，speed loss 到**多少 %** 算「正常/需警戒/該安排養護」？（用於 dashboard 門檻與可信度。）

## D. 商務決策價值（20% — 對陽明營運方）

15. 貴司目前排定 UWC/PP 的**實際決策觸發點**是什麼（speed loss %？油耗增額？固定週期？）？ROI 試算用的燃料單價假設？
16. 命題要我們列「希望額外取得哪些資料」——反問：貴司手上有但這次未釋出、對決策最關鍵的是哪些（吃水俯仰 trim、海試曲線、antifouling 塗層年限、航線/港口）？
17. **CII / EU ETS / 碳合規**對貴司是真實決策驅動因子，還是加分包裝？（決定我們要不要重壓合規卡。）

## E. 簡報與流程（對主辦方）

18. 展示 12 分鐘＝8 分簡報 + 4 分 Q&A、**統問統答**（確認）。
19. Live demo 可否要求評審連場地 wifi？雲端故障時錄影可否替代？
