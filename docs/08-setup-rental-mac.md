# Rental Mac Setup Notes

This is a placeholder for Eddie's rental Mac setup.

Recommended baseline:

- Homebrew
- Git
- GitHub CLI
- Java 21
- Maven
- Node.js LTS
- pnpm or npm
- Docker Desktop
- AWS CLI
- AWS SAM CLI if needed
- Python 3
- VS Code or Cursor

Before the competition:

1. Sign in to GitHub.
2. Clone this private repo.
3. Install tooling.
4. Verify Java, Node, Docker, AWS CLI.
5. Do not store permanent secrets on the rental laptop.

Example verification:

```bash
git --version
gh --version
java -version
mvn -version
node -v
npm -v
docker --version
aws --version
```
