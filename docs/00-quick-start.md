# Quick Start

## What We Are Building

A practical AI decision-support system for Yang Ming fleet efficiency.

Current strongest MVP:

- Speed Loss dashboard
- Fuel-consumption normalization
- Hull-efficiency degradation detection
- Underwater cleaning / propeller polishing before-after comparison
- Bedrock-generated operations brief

## Current North Star

Do not build a generic shipping chatbot.

Build a focused decision-support product that helps Yang Ming answer:

> Which vessels are showing hull-efficiency degradation, how much fuel/speed loss does it imply, and should a human expert review cleaning or propeller polishing timing?
