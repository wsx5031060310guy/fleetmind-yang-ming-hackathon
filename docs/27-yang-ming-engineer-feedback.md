# 27 · 陽明工程師回饋 → 需求變更（Day1 現場 Q&A）

> 來源：Day1 現場與陽明海運工程師的 Q&A（隊員整理）。**這是我們最直接的命題方需求**，優先於先前的推測。凡與早期 docs 衝突，以本檔為準。

## 1. 十點回饋（重點）

| # | 工程師說法 | 對系統的影響 |
| --- | --- | --- |
| 1 | **維修/進塢（Dry Dock）後油耗不一定立刻改善**——多數會，但也有做完幾乎沒變的案例 | AI **不得**假設 `DryDock ⇒ FuelSaving`；只能說「較高機率改善」。before/after 誠實量測，不寫死改善 |
| 2 | **船底清洗效果會遞減**——每刷一次漆磨損、表面變粗、更易附著；第 1 次可撐 ~6 月、第 2 次 ~3 月、第 3 次甚至幾週 | ⭐ **高加分**：加入「距上次 Dry Dock 多久」「清洗次數」；效果隨次數衰退（FRESH→DIMINISHING→DEPLETED） |
| 3 | **UWILD = Underwater Inspection，只是潛水員下去看（藻/藤壺/附著/損傷），不是清洗** | UWILD 當 **Inspection Event**，不視為改善事件（我們的 UWI 已不重置任何時鐘 ✓） |
| 4 | **15 艘船基本同型**（大小/建造年代相近） | 模型**不必**特別加 Ship Type；差異很小（W1/W2 僅當輕特徵） |
| 5 | **BLSF 燃料要可自由切換**（未來不要寫死 Fuel Type：HFO/LSFO/BLSF…） | Fuel Type 參數化，不 hardcode VLSFO |
| 6 | **Speed Loss 門檻要 Admin 可自行設定**（例：15%）→ 超過就跳通知/Email/Alert；想改 10% 直接改，不必找工程師 | ✅ **必做**：Threshold 執行期可調 + 告警 |
| 7 | **門檻沒有固定值**——公司自己決定（今天 8%、明天 12% 都行） | Threshold **不可寫死**，做成可設定 |
| 8 | **不是看時間（不是每 6 個月）**——真正看的是**同航速下油耗增加多少 %**（例：100→110 ton/day = +10% 就可能要清） | 監控 = **Fuel Consumption Increase %**，非時間週期（我們的 `k = FOC/STW³` 正是同速正規化後的效能指標 ✓） |
| 9 | **ROI/成本不用算**——成本是別部門管，他們只負責「發現問題、通知需要清洗」 | ❌ **移除** ROI/金額模型；不做成本估算為主線 |
| 10 | 若真要估，可用**公開油價**粗估（例：年 150 萬噸，多耗 1% = 1.5 萬噸 × 公開油價）——但每港/每次加油不同，只是估算、非正式數字 | 🔸 選配加分：估算**多耗燃油噸數（噸，不談金額）**，明標為粗估 |

## 3. 高分方向：從「預測」升級為「決策支援」

命題名稱是「AI 船舶效能分析與**節能決策支援系統**」。dashboard 應直接給決策，而非只給預測數字。每船顯示：

```
🟢 目前 Speed Loss：9.2%（正常，門檻 10%）
🟡 預估 20 天後將超過 10% 門檻
🔴 建議安排 UWILD 檢查
🔴 若確認附著物過多，建議安排 Hull Cleaning
⚙️ Alert Threshold：可由使用者設定（8% / 10% / 15%）
```

## 4. 我方對應（實作狀態）

- **監控指標**：`k = FOC / STW³`（同速正規化的油耗效能）＝工程師要的「同航速下油耗增加 %」。✅ 已是核心。
- **UWILD=inspection**：`Attribution`／污損時鐘對 UWI 不重置、不視為改善。✅ 已做。
- **Threshold + 告警 + forecast + 決策建議 + Cleaning 衰退 + 燃料切換 + 去 ROI**：`feat/decision-support`（core-calc `DecisionSupport` + `MetricsExportCli` + apps/api `/api/config/threshold`、`/api/alerts`、SNS Email hook）。
- **UI 決策支援化 + 升級**：後端就緒後改版 dashboard（狀態燈 + 建議 + 門檻設定）。
- **ROI 金額**：主線移除；保留「多耗燃油噸數」粗估（選配、不談金額）。

> 早期 `docs/13` 的 ROI 回本天數／`docs/23` 反事實金額為賽前推測，**依本檔降級**：不以金額為賣點，改以「效能衰退→門檻告警→分級養護建議」為主故事。
