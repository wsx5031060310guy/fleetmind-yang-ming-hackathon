啟用的告警通道

Email 收件人

燃料類型對應表

把來源雜亂燃料名（raw）正規化為標準碼（canonical），供 FOC 比較與 k 值分群。查無對應時套用預設碼並標記 FUEL_TYPE_UNMAPPED。

資料來源模式

baked＝映像內 real-metrics.json；upload＝人工上傳；apiPush＝系統介接推送。此為顯示／意圖設定。

介接 API 端點
